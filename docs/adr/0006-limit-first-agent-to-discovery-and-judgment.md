# Limit the first Agent to discovery and judgment

The first SourceOS Agent will collect, assess, revise discovery plans, and draft Need Hypotheses; it may read Outcome Feedback from delivered products and services to calibrate future discovery. It will not create development work, merge code, release products, set prices, contact customers, sell, or collect payment, because proving discovery quality is the first product loop and must not be obscured by a full-lifecycle automation project.
