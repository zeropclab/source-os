# Bound the Discovery Agent to approved public collection

SourceOS will use a Discovery Agent that may plan and execute collection only inside an Approved Collection Boundary: approved public sources, allowlisted tools, and fixed request, time, and cost limits. The operator must approve any source or boundary change, credentialed or subscription access, budget expansion, external contact, publication, product commitment, or development authorization; this preserves autonomous learning where it is cheap and reversible without delegating irreversible business decisions.
